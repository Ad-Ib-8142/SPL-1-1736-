Dhaka GSI consolidated dataset bundle

Extract this ZIP directly inside your project's data/datasets/ folder. It does not contain an enclosing project folder or nested ZIP archives.

Top-level folders: elevation, roads, waterways, drainage, rainfall, temperature, soil, meteorology, historical_flood, waterlogging, metadata, source_reference, waste_infrastructure, administrative_reference.

The source_reference folder contains original reference files unpacked from the raw-upload archive. These are not necessarily cleaned modelling inputs.

CRS, units, coverage, lineage, readiness and limitations are documented in metadata/ and the README files included with individual datasets. The DNCC+DSCC boundary is provisional and has 2018 lineage; its current official status is unverified.

No original source archive is included inside this bundle, and no nested ZIP files are intentionally retained.
